Installing binaries
===================

**fresnel** is available on conda-forge_ for the *linux-64*, *osx-64*, *osx-arm64*, and **win-64**
architectures. Install with:

.. code-block:: bash

    micromamba install fresnel

The fresnel builds on conda-forge_ support CPU rendering.

.. _conda-forge: https://conda-forge.org/docs/user/introduction.html
